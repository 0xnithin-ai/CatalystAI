01 — Problem understanding

The trial-and-error bottleneck is costing years and millions

The global push toward sustainable aviation fuel, green methanol, and bio-based chemicals is fundamentally constrained by a discovery problem. The theoretical design space for novel molecules exceeds 1060 candidates. Real laboratories can screen perhaps a few hundred a month. The gap between these two numbers is where competitive advantage lives — or dies.

For GPS Renewables' NG SAF initiative — India's first commercial-scale Ethanol-to-Jet plant — this is not an abstract concern. Every percentage point of improvement in the oligomerisation catalyst's selectivity translates directly to unit economics at scale. Every week saved in finding a more thermostable cellulase enzyme shortens the timeline to commercial lignocellulosic ethanol.

The core constraint is not bench capacity — it is iteration intelligence. Traditional screening consumes resources on uninformed candidates. The winning approach is to make every experiment count, ensuring each wet-lab result maximally updates the system's knowledge about the unexplored design space.

Two distinct but interconnected challenges

Chemical catalysis

Identifying heterogeneous catalysts for CO₂ → methanol, syngas → ethanol, and ethanol → SAF requires navigating a brutal activity/selectivity trade-off. High temperatures activate CO₂ but promote the reverse water-gas shift reaction. No existing database lookup resolves this — it requires generative design in unexplored compositional space.

Synthetic biology

Engineering microbial cell factories to convert lignocellulosic paddy straw into ethanol requires synergistic enzyme cocktails and rebalanced metabolic flux. A single enzyme insert alters the entire intracellular network — without stoichiometric modelling, this yields toxic intermediate accumulation and stunted product titres.

GPS Renewables' specific context: The HEFA pathway — dominant globally for SAF — is not scalable in India. Used cooking oil collection infrastructure is fragmented; imports face regulatory caps. The indigenous alternative is second-generation lignocellulosic ethanol → jet fuel. Our platform targets exactly this pathway: from biomass degradation enzymes to oligomerisation catalyst optimisation.

02 — Solution overview

CatalystAI: from database search to continuous generative discovery

CatalystAI is not a search engine for molecules. It is a closed-loop discovery engine that generates novel candidates, predicts their performance, recommends experiments, and learns from every result — successful or not. The system explicitly treats wet-lab experiments as information-gathering exercises guided by Bayesian acquisition functions, not validation tasks.

03 — AI / ML approach

Four algorithmic layers, one coherent pipeline

The platform integrates four complementary ML paradigms in a cascaded pipeline. Each layer is purpose-built for its role; no single approach is asked to do more than it does well.

Layer Method Role in pipeline Key models
Retrieval RAG + vector search Ground baseline performance; extract kinetics from literature Milvus / Qdrant, domain LLM
Generation Diffusion models Propose novel crystal lattices and enzyme backbones DiffCSP, cond. cDVAE, RFdiffusion
Prediction Equivariant GNNs Rapid surrogate for adsorption energies, stability, activity PyTorch Geometric, GNoME-style
Biology Protein LMs + FBA Sequence design, mutation fitness, metabolic flux ESM3, ProteinMPNN, COBRApy

Why generative models, not just retrieval-augmented generation

RAG is excellent at extracting and synthesising known information. It cannot propose a catalyst composition that has never been synthesised, or a protein sequence that has never existed in nature. The platform's generative core — diffusion models operating in latent material and sequence space — is what makes it capable of producing novel intellectual property rather than recombining existing knowledge.

Specifically: DiffCSP generates stable crystal lattice geometries conditioned on target electronic properties; RFdiffusion generates enzyme backbone scaffolds tailored to specific substrate geometries; ProteinMPNN then maps these scaffolds to viable amino acid sequences. The output is structurally novel, thermodynamically plausible, and immediately actionable.

Bayesian acquisition functions are not optional. The difference between a discovery tool and a discovery platform is how it handles uncertainty. CatalystAI outputs both a predicted mean performance value and an associated epistemic variance for every candidate. The Expected Improvement acquisition function then ranks candidates not by predicted score alone, but by their information value — explicitly balancing exploitation of confident predictions against exploration of uncertain but potentially high-value regions.

Metabolic pathway design

For the synthetic biology track, Flux Balance Analysis via COBRApy provides genome-scale constraint-based modelling of the microbial host. The platform formulates the metabolic network as a stoichiometric matrix and solves it using mixed-integer linear programming to identify the gene knockout and heterologous pathway insertion strategy that maximises target product yield. Deep learning surrogates accelerate gap-filling — automatically identifying missing enzymatic reactions and proposing candidate insertions from KEGG and BiGG databases.

Modular, cloud-native, and laboratory-integrable

API Layer
FastAPI (Python, async) — RESTful endpoints for all pipeline stages; JWT-based multi-tenant auth; role-based access control separating proprietary GPS process parameters from shared training data.

Materials microservice: DiffCSP / conditional cDVAE for crystal lattice generation. Biology microservice: RFdiffusion backbone → ProteinMPNN sequence → ESM3 zero-shot fitness. Both served via NVIDIA Triton Inference Server for concurrent execution.
Prediction
PyTorch Geometric GNNs for adsorption energy and stability prediction (trained on Open Catalyst Project, 260M+ DFT calculations). COBRApy + MILP for metabolic flux simulation. Active Learning
Feedback loop controller — manages the design-make-test-analyse cycle asynchronously. Listens for eLabFTW / Labtools.AI webhook events, validates incoming experimental data (human-in-the-loop flag for anomalies), triggers localised transfer learning retraining, versions model artefacts immutably. Orchestrated via Apache Airflow DAGs.
Data Layer
Vector DB (Milvus): molecular + protein embeddings for semantic similarity search. External APIs: Open Catalyst Project, Materials Project, BRENDA, Protein Data Bank, UniProt, KEGG, BiGG, ModelSEED. Literature agents: LLM-powered extraction of kinetic parameters from unstructured publications and patents → structured ingestion.

05 — Data feedback loops

The Lab-in-the-Loop: how negative results become competitive advantage

Most screening platforms discard failed experiments. CatalystAI treats them as first-class data. A candidate that underperforms its predicted activity is maximally informative: it reveals exactly where the surrogate model's structural representation is deficient.

Mechanics of the active learning cycle

1. Uncertainty-aware prediction

GNN surrogate models output a predicted mean + epistemic variance per candidate, quantified via deep ensembles. This variance is not decorative — it drives candidate selection.

2. Expected Improvement ranking

Candidates are ranked not by predicted score but by Expected Improvement — the probability-weighted gain over the current best. This balances exploitation of known-good regions against exploration of high-uncertainty space.

3. Validated ingestion

Experimental results enter via eLabFTW / Labtools.AI API. A human-in-the-loop validation step flags sensor anomalies and contamination events before data is committed to the training repository.

4. Transfer learning retraining

Localised fine-tuning adjusts model weights toward the specific assay conditions and reactor environment of GPS Renewables' lab. Immutable model artefacts are versioned after each cycle — full provenance, no silent degradation.

Data provenance and quality control: Every data point entering the training corpus is tagged with its source (published literature, internal assay, high-throughput screening), confidence tier, and ingestion timestamp. Conflicting literature data points are flagged for expert review rather than silently averaged. Proprietary GPS Renewables data is cryptographically isolated in a tenant-specific shard and never incorporated into public model weights.

Model drift safeguards

After each retraining event, the updated model is benchmarked against a held-out validation set of historically confirmed experimental results before being promoted to production. If performance regresses on the validation set, the retraining is rolled back and the anomaly is surfaced to the platform administrator. This prevents gradual model drift from accumulating silently across dozens of feedback cycles.

06 — Scientific UX

Visualisations designed around how researchers actually think

The dashboard is not a generic data tool with molecular data loaded in. It is purpose-built around the cognitive workflow of a process chemist and a metabolic engineer — two very different mental models that the platform must serve simultaneously.

3D Pareto front explorer

Plotly scatter plot mapping candidates across activity, selectivity, and stability axes simultaneously. Researchers drag-select frontier points representing optimal trade-offs. Novel AI-generated candidates are visually distinguished from database retrievals.

Molstar molecular viewer

WebGL-accelerated 3D rendering of generated crystal lattices and protein folds. GNN-predicted saliency maps overlay atomic interaction hotspots as a colour-coded heatmap. Mutation impact predictions visualised directly on the 3D structure.

Metabolic flux map

Cytoscape.js network diagram of the microbial host's metabolic pathways. Edge thickness encodes calculated FBA flux volumes. Bottleneck reactions and toxic intermediate accumulation zones are flagged with colour coding.

Experiment kanban + feedback tracker

Candidates progress from computational recommendation → synthesis → wet-lab testing → result logging. Predicted vs actual performance discrepancies are surfaced automatically, with structural hypotheses flagged for follow-up.

The platform must explain why it makes its recommendations. Structural saliency maps generated by GNN attention mechanisms highlight the specific atomic coordination environments driving activity predictions — empowering the scientist to reason about the AI's logic, not just trust its output.

07 — Safety and biosecurity

Dual-use risk is non-negotiable: the TEVV framework

The same protein language models that design efficient biomass-degrading enzymes are capable — without guardrails — of generating sequences with structural homology to known toxins or pathogenic agents. This is not a theoretical risk: published biosecurity benchmarks have demonstrated that frontier generative models can produce sequences with structural similarity to restricted agents like diphtheria toxin that evade standard synthesis screening software.

CatalystAI enforces a mandatory Testing, Evaluation, Validation and Verification (TEVV) layer:

All generated biological sequences are automatically cross-referenced against databases of known virulence factors, toxins, and restricted pathogen sequence motifs using structural homology alignment before any candidate is surfaced to the researcher or exported to a synthesis provider. Any match above a configurable similarity threshold triggers automatic blocking, administrator alert, and permanent audit logging. This layer cannot be bypassed by any user role.

Additionally, the platform implements role-based access controls distinguishing general discovery use from export-to-synthesis workflows, with the latter requiring elevated permissions and automatic compliance documentation.

11 — Risks and mitigations

Known failure modes, addressed in the architecture

Hallucinated chemistry

Diffusion models can generate structures violating basic valency rules or steric constraints. Mitigation: RDKit-based physics-informed heuristic filters run immediately downstream of every generation step. Invalid chemistry never reaches the prediction layer.

Out-of-distribution failure

GNN surrogates trained on known catalysts degrade on truly novel compositions. Mitigation: Epistemic uncertainty quantification (deep ensembles) flags low-confidence predictions. Expected Predictive Information Gain prioritises experiments that resolve OOD uncertainty.

Noisy literature data

Scraped kinetic parameters from publications frequently conflict. Mitigation: Automated conflict detection flags inconsistent values; human expert review is required before contested data enters training. GPS in-house data is heavily weighted over literature.

Model drift on retraining

Incremental fine-tuning on small experimental batches can degrade performance on previously well-modelled chemical spaces. Mitigation: Held-out validation benchmark run before every model promotion. Automatic rollback if regression detected. Immutable artefact versioning.
